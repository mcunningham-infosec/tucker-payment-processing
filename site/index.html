What this site will become

Tucker Payment Processing is a pretend payment company with a real AI customer-support agent. It shows, hands on, how a customer-facing AI should be governed and secured.

  • A guided tour that starts as soon as you arrive, narrated by Tucker.
  • Chat with Tucker about accounts, transactions and company policies (all fictional).
  • A live "Behind the Scenes" panel showing the code path and every guardrail as it fires: identity checks, card-number masking, prompt-injection defenses and spending limits.
  • Tucker's Treat Shop, a demo checkout that can't be tampered with.
  • Version 2: Blackie hosts an "attack Tucker" section where you try to trick the AI and see how it holds up.

Built in the open: view the code on GitHub.

Tucker Payment Processing is a fictional company created as a technology demonstration. It does not process real payments. All data is fictional.
