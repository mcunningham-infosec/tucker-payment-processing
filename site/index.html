What this site will become

Tucker Payment Processing is a pretend payment company with a real AI customer-support agent. It shows, hands on, how a customer-facing AI should be governed and secured.

  • A guided tour that starts as soon as you arrive, narrated by Tucker.
  • Chat with Tucker about accounts, transactions and company policies (all fictional). Live now in beta.
  • A live "Behind the Scenes" panel showing the code path and every guardrail as it fires: identity checks, card-number masking, prompt-injection defenses and spending limits.
  • Tucker's Treat Shop, a demo checkout that can't be tampered with.
  • Version 2: Cipher hosts an "attack Tucker" section where you try to trick the AI and see how it holds up.

The company is pretend. The technology is not.

Tucker Payment Processing is a demo, but everything behind it is the real thing, built and secured the way a production system should be:

  • Google Gemini powers Tucker's AI, on the paid tier, so visitor chats are not used to train the model, with a hard monthly spending cap.
  • Google Cloud hosts the site on a hardened Ubuntu Linux server running Apache, with Python and PostgreSQL behind the chat.
  • HTTPS everywhere with an automatically renewing Let's Encrypt certificate.
  • Zero-trust admin access: no admin port open to the internet; administrators get in only through Google's identity-checked tunnel with two-factor authentication.
  • Least privilege and privacy by design: the server has no cloud permissions, the site is read-only, and there are no tracking cookies.
